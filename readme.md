# Gestion des tâches

## Description
Application Python simple pour gérer les tâches quotidiennes.

## Fonctionnalités
Ajouter une tâche.
Afficher toutes les tâches.
Rechercher une tâche.
Quitter le programme.

## Fichiers
main.py : code source du programme.
README.md : description du projet.

## Étapes réalisées
Création du programme Python.
Ajout des fonctionnalités.
Test du programme.
Utilisation de Git et GitHub.

## Exécution
Ouvrir le fichier main.py dans VS Code.
Cliquer sur Run Python File.
